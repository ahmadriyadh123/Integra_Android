Nama menu menentukan label fitur. Model, field, filter, pengurutan, dan relasi menentukan struktur data yang dipratinjau.

Kredensial dikirim ke server web untuk permintaan metadata, tidak disimpan, dan wajib dimasukkan ulang saat mengedit fitur.
Pilih field relasi; field model tujuan akan dimuat dari Odoo tenant.
Filter hanya boleh memakai field yang dipilih. Untuk operator in/not in, masukkan daftar sebagai JSON (mis. [1,2]) atau nilai dipisahkan koma.

Menu dapat dipratinjau dari akun Odoo tenant yang dimasukkan. Konfigurasi ini disimpan di web admin dan belum otomatis mengubah menu aplikasi lain; integrasi pipeline fitur tetap diperlukan. Pratinjau hanya menampilkan data yang dapat dibaca akun Odoo tersebut.
